Wishlist App

Overview:

    The Wishlist App is an Android application built using Kotlin and Room Database.
    It allows users to create, manage, and organize a wishlist of items efficiently.
    The app follows the MVVM architecture for  better scalability and maintainability.

Features:

    Add, edit, and delete wishlist items.

    Persistent data storage using Room Database.

    MVVM architecture with ViewModel.

    User-friendly UI with smooth interactions.

Technologies Used:

    Kotlin - Primary language for Android development.

    Room Database - Local database for storing wishlist items.

    MVVM Architecture - Ensures separation of concerns and better maintainability.

    ViewModel - For efficient data handling and UI updates.

Installation & Setup:

    Clone the repository

    Open the project in Android Studio.

    Sync Gradle dependencies.

    Run the application on an emulator or physical device.

Usage:

    Open the app and start adding wishlist items.

    Click to edit and slide to delete an item.

    The data is stored locally using Room Database, ensuring persistence.

Future Enhancements:

    Implement cloud sync using Firebase.

    Add categories and filters for better item management.
